# Atelier Kitchen Experience

Build a premium, production-quality website for a modern restaurant called "Atelier Kitchen."

IMPORTANT DESIGN DIRECTION

This website should NOT look AI-generated.

It should look like it was designed by an award-winning UI/UX designer for a luxury restaurant brand using Squarespace or WordPress.

The overall quality should be comparable to Michelin-star restaurants, Nobu, Alinea, Apple, Aesop, or premium Webflow/Squarespace showcase websites.

Avoid generic restaurant templates.

Avoid oversized rounded blobs.

Avoid excessive animations.

Avoid bright colors.

Avoid gradients completely.

DO NOT use gradient backgrounds, gradient buttons, gradient overlays, glowing effects, neon colors, or glassmorphism.

Use solid colors only.

The design language should communicate elegance, craftsmanship, warmth, sophistication, and premium dining.
